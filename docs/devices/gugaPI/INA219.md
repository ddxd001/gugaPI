# INA219 与电源保护手册

## 启动

`Board_Ina219Init()` 从总线表取得 `ina219` 配置，启用 I2C 引脚上拉并写默认配置与
校准寄存器。应用层 `App_Ina219Init()` 加载保护参数；`App_Run()` 每 100 ms 尝试
采样，不增加调度任务。

## 硬件和换算参数

- 7 位地址：`0x40`（可在 `0x40..0x4F` 范围诊断）。
- 分流电阻：5 mΩ。
- Current LSB：200 µA/bit。
- 当前板级配置 `invert_current=1`。
- 默认 INA219 配置寄存器：`0x399F`。

必须用实际原理图和精密电流源确认分流电阻、方向与量程，不能只依据软件常量。

## 保护参数

ConfigStore 名称与默认值：

| 参数 | 默认 | 含义 |
|---|---:|---|
| `ina_uv_trip_mv` | 6000 | 欠压进入阈值 |
| `ina_uv_release_mv` | 6500 | 欠压恢复阈值 |
| `ina_oc_trip_ma` | 5000 | 绝对值过流进入阈值 |
| `ina_oc_release_ma` | 4500 | 绝对值过流恢复阈值 |
| `ina_trip_samples` | 3 | 连续异常样本数 |
| `ina_release_samples` | 5 | 连续恢复样本数 |
| `ina_comm_fail_samples` | 3 | 连续通信失败数 |
| `ina_latch_faults` | 0 | 是否锁存故障 |
| `ina_motion_inhibit` | 0 | 是否请求运动禁止 |

默认阈值只是软件占位基线，自动运动禁止默认关闭。完成电池、线束和负载整定后再设置
`ina_motion_inhibit=1` 并 `param save`。

故障位：bit0 欠压、bit1 过流、bit2 通信、bit3 数学溢出、bit4 转换未就绪。

## 使用

```text
ina219 status
ina219 read
ina219 raw
ina219 protect status
ina219 protect clear
param set ina_uv_trip_mv 7000
param set ina_uv_release_mv 7400
param save
```

`Chassis_*` 的非零运动命令会检查保护请求；保护置位后 `App_Run()` 也执行一次停止。
这是应用级保护，不是硬件安全回路。

## 验证

先保持运动禁止关闭，校验电压、电流和方向；再用可限流电源测试滞回、连续计数、通信
断线、锁存清除和复位恢复。最终测量从阈值越界到实际执行器停止的时间。
