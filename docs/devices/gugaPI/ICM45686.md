# ICM45686 手册

## 启动

启用 IMU 功能后，`Board_ImuInit()` 配置共享 SPI 和两个片选，然后独立初始化
ICM45686 与 LIS3MDL。ICM 初始化执行软复位、WHO_AM_I 校验和传感器配置；失败结果
记录为 `icm45686` 的禁止运动级启动故障，但共享 SPI 仍保留给诊断和重试。

## 主要参数

- SPI：SysConfig 的 `IMU_SPI`，1 MHz、8 bit、mode 3；设备访问固定恢复到 mode 3。
- 每字节/空闲等待上限：100000 次轮询。
- 默认加速度量程：±4 g。
- 默认陀螺量程：±1000 dps。
- 加速度和陀螺 ODR：200 Hz。
- 应用采样任务周期：5 ms；每次从 `ACCEL_DATA_X1` 开始突发读取 14 字节。
- WHO_AM_I 期望值由驱动常量校验。

## API

```cpp
board::Board_Icm45686Init();
board::Board_Icm45686ReadWhoAmI(&who);
board::Board_Icm45686ReadSensors(&sample);
board::Board_Icm45686ReadRegister(reg, &value);
board::Board_Icm45686WriteRegister(reg, value);
```

`Board_ImuIsReady()`/`Board_ImuSpiIsReady()`只表示共享 SPI 和引脚可用；设备是否通过
初始化必须检查 `Board_Icm45686IsReady()` 或 `Board_Icm45686GetInitStatus()`。

运行期 `AppImuData` 提供 `valid`、`last_update_ms`、`error_count`、`last_status` 和
`sequence`。航向控制拒绝超过 200 ms 的旧数据。

当前没有启用 INT1 数据就绪、FIFO 或 DMA。200 Hz 下单次 SPI 线上时间约 120 us，
同步突发仍有足够余量；后续只有提升到 400/800 Hz 并启用 FIFO 批量读取时才建议加入
DRDY + SPI DMA。

## Shell

```text
imu status
imu icm init
imu icm whoami
imu icm sample
imu icm reg 0x72
imu spi mode 3
```

## 故障与验证

SPI TX、RX 和 BUSY 等待都返回真实超时；片选在错误路径也会释放。验证应覆盖断开器件、
WHO_AM_I 错误、持续 BUSY、三轴静止零偏、已知旋转方向和连续采样时间戳。还需用逻辑
分析仪确认 SCLK 约 1 MHz、mode 3、一次采样包含 1 个地址字节和 14 个数据字节，并检查
200 Hz 连续采样时 `sequence` 不停顿。
