第一次使用图形序列编辑器

这个编辑器把当前画布编译成固件可脱机执行的 ActionRunner 指令，不会生成依赖上位机在线发送的脚本块。

1. 拖入动作

从左侧动作库拖到画布；点击动作后在右侧设置中文参数。

2. 连接端口

从动作块右侧圆点拖到目标块。绿色表示完成；红色表示失败或超时，留空时默认终止序列并停车。

3. 先试运行

试运行只临时更新 MCU RAM，校验并回读比对后启动，不会写 FRAM。

4. 再保存

保存会覆盖绑定槽位，写入后自动通过 seq dump 逐项比对。

运动动作具有机械风险。实车测试前请架空车轮，并确保“紧急停止”按钮始终可操作。
