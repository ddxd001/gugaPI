# 无 MCU DRV8876 右侧 MR 单电机迁移

## 当前结论

无 MCU 电机板保持原 PCB 网络，不再要求交换 U9-11/12 与 U9-15/16。
在这个约束下，右侧 `MR` 和左侧 `ML` 都可以**单独**使用硬件 PWM 和
硬件 QEI，但两侧编码器可用的引脚复用都占用 `TIMG8`，不能同时启用。
当前实现选择右侧 `MR`（DRV8876 通道 2），因为它可以沿用现有 PC0/PC1
QEI 配置，改动最小：

- `PWM2 / GPIO2 / NSLEEP2` 驱动右侧 `MR_OUTP/MR_OUTN`。
- `GMR_RA/GMR_RB` 是右电机编码器。
- 主控使用 `PB13/TIMG12_CCP0` 输出 20 kHz PWM。
- 主控使用 `PC0/PC1` 上的 `TIMG8` 读取硬件正交编码器。

当前固件配置应满足：

```text
FEATURE_LOCAL_MOTOR_RIGHT_ONLY       = 1
FEATURE_ENABLE_DIFFERENTIAL_CHASSIS  = 0
```

这只是右侧单电机台架配置，不是可运行的双轮底盘配置。双轮差速、
`chassis vel`、航向闭环、编码器定距、循迹、路口自动控制和动作序列中的
行驶/转弯动作均不可用于实车运动。旧外置 MCU MotorDriver 后端仍保持关闭。

## 原电机板通道对应关系

| 电机板通道 | DRV8876 | 控制信号 | 电机输出 | 编码器 |
| --- | --- | --- | --- | --- |
| 通道 2 / 右侧 MR | U2 | `PWM2`、`GPIO2`、`NSLEEP2` | `MR_OUTP/MR_OUTN` | `GMR_RA/GMR_RB` |
| 通道 1 / 左侧 ML | U1 | `PWM1`、`GPIO1`、`NSLEEP1` | `ML_OUTP/ML_OUTN` | `GMR_LA/GMR_LB` |

原板 U9-11/12 本来就是两路 PH/方向输入，U9-15/16 本来就是左编码器
A/B。此前计划的网络交换无法实现，因此不能继续使用此前的双轮引脚方案。
当前选择右侧 MR；如果以后改为左侧 ML 单电机，可将 PB15/PB16 整体
重映射为 `TIMG8_CCP0/1`，并改用 PB14/PB9/PA11 控制左桥。这个 ML
备选与 PC0/PC1 上的 MR QEI 互斥，不能让 TIMG8 同时解码两组编码器。

## U9 原接线与单电机用途

| U9 | 主控 MCU | 电机板原网络 | 当前用途 | 软件资源/安全状态 |
| ---: | --- | --- | --- | --- |
| 1 | 5V | 5V | 电机板逻辑电源 | 必须连接 |
| 2 | GND | GND | 公共地 | 必须连接 |
| 3 | - | 未使用 | NC | 不配置 |
| 4 | - | 未使用 | NC | 不配置 |
| 5 | - | 未使用 | NC | 不配置 |
| 6 | - | 未使用 | NC | 不配置 |
| 7 | PA10 | `NSLEEP2` | 右 MR 桥使能 | GPIO，复位/停车时低 |
| 8 | PA11 | `NSLEEP1` | 左 ML 桥使能 | GPIO，始终保持低 |
| 9 | PC0 | `GMR_RB` | 右编码器 B | TIMG8 CCP0 |
| 10 | PC1 | `GMR_RA` | 右编码器 A | TIMG8 CCP1 |
| 11 | PB7 | `GPIO2` | 右 MR 桥 PH/方向 | GPIO，默认低 |
| 12 | PB9 | `GPIO1` | 左 ML 桥 PH/方向 | GPIO，保持低 |
| 13 | PB13 | `PWM2` | 右 MR 桥 EN/PWM | TIMG12 CCP0，20 kHz |
| 14 | PB14 | `PWM1` | 左 ML 桥 EN/PWM | 当前不配置；ML 备选 TIMG12 CCP1 |
| 15 | PB15 | `GMR_LA` | 当前未用；ML 备选编码器 A | MR 配置不得输出；ML 备选 TIMG8 CCP0 |
| 16 | PB16 | `GMR_LB` | 当前未用；ML 备选编码器 B | MR 配置不得输出；ML 备选 TIMG8 CCP1 |

特别注意：

- PB7 不再作为左 QEI；它必须作为右桥 `GPIO2/PH` 输出。
- PB15/PB16 不再作为 PH 输出。它们实际连接左编码器输出，配置成 MCU
  输出会产生电气争用。
- PB15/PB16 可以作为另一套 TIMG8 CCP0/1 输入，但只能在专门的 ML
  单电机配置中使用；它们不能与 PC0/PC1 的 MR QEI 同时工作。
- 左桥以 PA11 的 `NSLEEP1=0` 保持硬件休眠；PB14 当前不启用 PWM，PB9
  保持低。单电机验收期间不要在左侧接电机。
- U9-3～6 没有使用，不要为了“补齐接口”随意连接。

## 右侧 CN6 接口

应使用原理图标注为 `CN6 RIGHT / MR` 的接口。按所给 PCB 正视渲染，
这个接口位于画面的左侧，不能仅凭画面左右判断。

| CN6 脚号 | 网络 | 用途 |
| ---: | --- | --- |
| 1 | `MR_OUTP` | 右电机端子 |
| 2 | GND | 编码器地 |
| 3 | `GMR_RB` | 右编码器 B |
| 4 | `GMR_RA` | 右编码器 A |
| 5 | 3V3 | 右编码器电源 |
| 6 | `MR_OUTN` | 右电机端子 |

确认编码器允许使用 3.3 V 供电和 3.3 V 信号后再连接。CN6-1/6 是 H 桥
电机输出，不能接地或接编码器电源。

## 供电

- U9-1 的 5V 为电机板逻辑电源，不能代替电机功率电源。
- 电机功率由 CN1 的 12V/GND 提供。
- U9-2、CN1 GND 和主控 GND 必须共地。
- 第一次带电机测试必须使用限流电源，并保留可立即切断 12V 的开关。
- 电机板没有把 `nFAULT1/2` 接回主控，软件无法读取 DRV8876 硬件故障脚。

## 编码器方向

右编码器实际连接为：

```text
PC0 / TIMG8_CCP0 <- GMR_RB
PC1 / TIMG8_CCP1 <- GMR_RA
```

CCP 输入顺序为 B/A，因此计数符号可能与车辆约定的正方向相反。不要为了
改符号交换线路；先手转验收，再使用 `motor_encoder_invert_flags` 的 bit 0
校准右编码器。`motor_output_invert_flags` 的 bit 0 校准右电机输出方向。
两个参数的 bit 1 在右侧单电机配置中不参与运动控制。

## 安全行为

- 上电、初始化失败、正常停车、全局故障、50 ms 控制调度超时或 300 ms
  命令租约超时：右桥 PWM 归零并拉低 PA10/nSLEEP2。
- 左桥 PA11/nSLEEP1 始终保持低，不允许被任何运动命令唤醒。
- 开始运行时先设置 PB7/PH，再拉高 PA10/nSLEEP2；等待至少 1 ms 后才输出
  PWM。
- 换向时先将 PWM 降为零，确认失效后再改变 PB7/PH。
- 当前 50/300 ms 保护依赖协作主循环，不是独立硬件看门狗。主循环完全
  卡死时可能无法执行停车，因此台架必须保留人工断电能力。
- 单电机测试不能验证双轮停车、差速控制、航向控制或比赛动作的安全性。

## 首次台架验收

1. 不接 12V、不接电机，用万用表确认 U9 和 CN6 连通关系与上表一致；
   确认 U9-3～6 未连接，且没有实施 11/12 与 15/16 的网络交换。
2. 只接主控和 U9 逻辑电源，确认复位期间 PA10、PA11 均为低；运行后
   PA11 仍始终为低。
3. 不给 12V，手动转动右电机编码器，重复查看 `chassis status`；只允许
   右侧 count/cps 变化。确认 PC0/PC1 两相均有跳变。
4. 约定机械正转方向，手转并记录计数符号；必要时只调整
   `motor_encoder_invert_flags` bit 0 并保存。
5. 示波器确认 PB13 是 20 kHz PWM、PB7 是方向、PA10 仅在右电机命令期间
   拉高；同时确认 PA11 保持低、PB14 没有 PWM 输出。
6. 首次带电机前执行 `param set speed_max_duty 10` 和 `param save`，使用
   限流 12V。架空机构，仅下发右侧低速目标；双参数接口中左目标必须为 0，
   例如 `chassis wheel 0 30`。
7. 依次验收低速正转、`chassis stop`、低速反转和命令租约超时停车。
   出现异常电流、意外换向、编码器不计数或 nSLEEP 无法拉低时立即断电。
8. 单电机台架通过后只能记录“MR 通道验收通过”。在恢复第二路可用接线并
   重新启用 `FEATURE_ENABLE_DIFFERENTIAL_CHASSIS` 之前，不得进行航向、
   定距、循迹、路口或比赛动作测试。
